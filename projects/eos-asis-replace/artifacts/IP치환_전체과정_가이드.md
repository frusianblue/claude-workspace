# AS-IS IP → TO-BE IP 치환 전체 과정 가이드

IP 전수 조사(초안)부터 매핑표 작성, 치환, 검증, 엑셀 조회까지의 전체 절차.

## 준비물

| 파일 | 용도 |
|---|---|
| `Find-AsisPath.ps1` | IP 전수 조사 (초안 추출) + 치환 후 산출물 검증 |
| `Replace-AsisIp.ps1` | 매핑표 기반 일괄 치환 (DryRun 기본, 자동 백업) |
| `ip_mapping.dat` | IP 매핑표 (DRM 미대상 확장자, 메모장으로 편집) |

PowerShell 창 열고 최초 1회:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
cd D:\Utils\asis-find
```

---

## 1단계. IP 전수 조사 — 매핑표 초안 뽑기

소스에 어떤 IP가 박혀 있는지 먼저 전부 찾는다:

```powershell
.\Find-AsisPath.ps1 -Root "D:\work\소스명" -Pattern "(?<![\d.])(?:\d{1,3}\.){3}\d{1,3}(?![\d.])" -Out 소스명_ip전수.dat
```

- 모든 IP 형태(`숫자.숫자.숫자.숫자`)가 검출됨
- 리포트도 DRM 피하려면 `-Out`을 `.dat`로 (내용은 CSV 형식이라 엑셀에서 열람 가능 — 4단계 방법 참조)
- 소스 30개면 소스별로 반복하되 `-Out` 파일명에 소스명을 넣어 구분

### 결과에서 골라내기

리포트를 열어 Match 컬럼을 보고 분류한다:

| 검출 값 | 처리 |
|---|---|
| AS-IS 서버 실제 IP | **매핑표에 추가** (치환 대상) |
| `127.0.0.1`, `0.0.0.0`, `localhost` 계열 | 제외 — 서버가 바뀌어도 그대로인 값 |
| 버전 번호 (`1.2.3.4`), 라이브러리 내부 상수 | 제외 — IP가 아님 |
| 외부 기관/공공 IP (연계처) | 별도 확인 — 연계기관이 안 바뀌면 제외 |
| 용도 불명 IP | 인프라 담당에게 확인 후 결정 |

같은 IP가 여러 소스에서 나와도 매핑표에는 한 번만 넣는다 (OldIP 중복 금지).

---

## 2단계. 매핑표 작성 — ip_mapping.dat

**메모장으로** 작성한다 (엑셀로 편집·저장 금지 — DRM이 걸릴 수 있음).

```
업무코드,업무명,서버명,호스트명,OldIP,NewIP,OldPort,NewPort
EOS01,포털,WDAAD11,asis-web01,192.168.1.10,10.20.1.10,8080,9090
EOS02,리포팅,WDDIM11,asis-was01,192.168.1.11,10.20.1.11,,
EOS03,연계,WDIFD11,asis-if01,192.168.2.20,10.20.2.20,,
```

작성 규칙:

- 첫 줄 헤더 고정 (`OldIP`, `NewIP` 이름은 스크립트가 검증함)
- 포트가 안 바뀌면 뒤 두 칸 비움 — 단 콤마는 유지 (`...,10.20.1.11,,`)
- OldIP 중복 금지, 빈 값 금지 (실행 시 자동 검증되어 에러로 알려줌)
- localhost는 넣지 않는다
- 업무코드/업무명/서버명/호스트명은 리포트 표시·증적용

인코딩은 메모장 기본값(UTF-8) 그대로 저장하면 됨. 스크립트가 UTF-8/ANSI 모두 자동 인식.

## 3단계. 치환 실행

```powershell
# 1) DryRun — 파일 변경 없이 리포트만 생성
.\Replace-AsisIp.ps1 -Root "D:\work\소스명" -Map ip_mapping.dat -Out 소스명_ip치환.dat

# 2) 리포트 검토 (4단계 방법으로 엑셀에서 확인)
#    치환하면 안 되는 파일이 보이면 제외하고 다시 DryRun:
.\Replace-AsisIp.ps1 -Root "D:\work\소스명" -Map ip_mapping.dat -ExcludeFiles @("*Test.java","sample*")
#    제외 대상이 많으면 목록 파일로: -ExcludeList exclude.dat (한 줄에 하나, # 주석 가능)

# 3) 실제 치환 — 변경 파일 자동 백업 (_ip_backup_소스명_날짜시각\)
.\Replace-AsisIp.ps1 -Root "D:\work\소스명" -Map ip_mapping.dat -Apply

# 4) 검증 — 다시 DryRun 해서 "매칭 0건" 확인
.\Replace-AsisIp.ps1 -Root "D:\work\소스명" -Map ip_mapping.dat
```

포트까지 바뀌는 서버가 있으면 각 명령에 `-UsePort` 추가 (`IP:포트` 조합으로 치환, 포트 빈 행은 IP만).

문제 발생 시 롤백: 백업 폴더의 파일을 원래 위치에 덮어쓰면 됨 (원본 폴더 구조 그대로 백업됨).

---

## 4단계. 리포트를 엑셀에서 보기 (텍스트 마법사)

`.dat` 리포트/매핑표는 내용이 CSV 형식이므로 엑셀로 표처럼 볼 수 있다.
**단, 엑셀에서 저장은 절대 하지 않는다** — 조회 전용. 수정은 메모장에서.

### 방법 A. 복사 → 붙여넣기 → 텍스트 나누기

1. `.dat` 파일을 메모장으로 열고 전체 복사 (Ctrl+A, Ctrl+C)
2. 엑셀 빈 시트 A1에 붙여넣기 → 한 열에 몰려 들어감
3. A열 전체 선택 → **데이터 탭 → 텍스트 나누기**
4. 마법사 1단계: **구분 기호로 분리됨** 선택 → 다음
5. 마법사 2단계: **쉼표** 체크 → 다음
6. 마법사 3단계: 마침 → 컬럼별로 펼쳐짐

### 방법 B. 파일 직접 불러오기

1. 엑셀 → **데이터 탭 → 텍스트/CSV에서** (구버전: 데이터 → 외부 데이터 가져오기 → 텍스트)
2. 파일 형식을 "모든 파일"로 바꿔 `.dat` 선택
3. 미리보기에서 구분 기호 **쉼표** 확인 → 로드

### 보기 팁

- 첫 행 선택 → **데이터 탭 → 필터** 걸면 컬럼별 필터링 가능
- 치환 리포트는 `OldValue`로 필터 → IP별 분포 확인, `RelPath`로 필터 → 파일별 확인
- `업무명`/`서버명` 컬럼으로 필터하면 업무 단위 검토 가능
- 업무코드가 `001` 형태면 숫자로 표시될 수 있으나 조회용이므로 무시 (원본 .dat는 온전함)

---

## 5단계. 재빌드 후 산출물 검증

소스 치환 후 재빌드하고, 배포 산출물(class/jar/war)에 AS-IS IP가 남아있는지 확인:

```powershell
.\Find-AsisPath.ps1 -Root "D:\work\소스명" -Scope build -Pattern "(?<![\d.])(192\.168\.1\.10|192\.168\.1\.11)(?![\d.])" -Out 소스명_build검증.dat
```

- `-Pattern`에는 매핑표의 OldIP들을 `|`로 나열. **점은 반드시 `\.`로 이스케이프**
- 0건이면 완료
- **CLASS에서만 검출되고 대응하는 java 소스가 없으면** → 소스 유실분 신호. 디컴파일(CFR) 대상 목록에 추가

---

## 6단계. 파일 외 IP 확인 (치환만으로 끝나지 않음)

매핑표의 IP별로 아래 4개 영역을 체크리스트로 관리:

1. **DB 설정 테이블** — 연계 URL·서버 주소가 DB에 저장된 케이스. `SELECT`로 확인
2. **WAS/웹서버 설정** — LENA 인스턴스 설정, workers.properties(AJP), JNDI datasource. 서버 설정 디렉토리를 `-Root`로 별도 스캔
3. **OS hosts 파일** — 호스트명이 구IP로 매핑돼 있는지
4. **방화벽/연계기관** — 신IP 오픈 신청 완료 여부

---

## 전체 흐름 요약

```
1. 전수 조사   Find (IP 정규식) → *_ip전수.dat → AS-IS IP 선별
2. 매핑표     메모장으로 ip_mapping.dat 작성 (엑셀 저장 금지)
3. 치환       Replace DryRun → 엑셀로 리포트 검토 → 제외 반영 → -Apply → DryRun 0건
4. 재빌드
5. 산출물검증  Find -Scope build (OldIP 패턴) → 0건 확인 / CLASS만 검출 시 디컴파일 대상
6. 파일 외    DB 설정·WAS 설정·hosts·방화벽 체크
```

모든 `.dat` 리포트(전수/치환/검증)는 소스별로 보관 → 이관 전후 증적.
