# 도구 실행가이드 — Find-AsisPath v8.2 / Replace-AsisPath v3

AS-IS 하드코딩 경로(d:/) **전수 조사(Find)** 와 **매핑표 기반 치환(Replace)** 도구 통합 가이드.
기존 `Find-AsisPath_실행가이드.md`(v8 기준)를 대체한다.

배너 확인: 실행 첫 줄에 `Find-AsisPath v8.2` / `Replace-AsisPath v3` — 안 보이면 구버전.

---

## 1. 표준 흐름 (소스 1건당)

```
0. Find (기본 Scope=all)        → 전수조사 증적 + 매핑표 재료 + 소스유실 탐지
1. 경로 매핑표 작성              → Replace DryRun → 리포트 검토 → -Apply → 재DryRun 치환 0건
2. IP 매핑표                    → Replace-AsisIp DryRun→Apply→재DryRun 0건
3. 재빌드
4. Find -Scope build            → 구경로/OldIP 0건 확인 (치환 후 증적)
5. 파일 외 확인                  → DB 설정 테이블 / LENA·workers.properties / hosts / 방화벽
```

[중요] 치환 후 Find를 전체 패턴으로 다시 돌리면 **새 경로(d:/app/...)도 d:/라서 검출**된다.
치환 완료 증적은 **Replace 재DryRun 치환 0건**으로 남기고, Find는 전수조사·특정 구경로
검증(`-Pattern "d:[/\\]eos"` 식으로 좁혀서)에 쓴다.

---

## 2. 자주 쓰는 명령

```powershell
# ── Find ──
.\Find-AsisPath-v8.2.ps1 -Root "D:\src\portal"                    # 전수조사 (Scope=all)
.\Find-AsisPath-v8.2.ps1 -Root "D:\src\portal" -Scope src         # 소스 증적용
.\Find-AsisPath-v8.2.ps1 -Root "D:\src\portal" -Scope build       # 재빌드 후 검증
.\Find-AsisPath-v8.2.ps1 -RootList .\roots.dat                    # 여러 소스 일괄

# ── Replace ──
.\Replace-AsisPath-v3.ps1 -Root "D:\src\portal" -Map .\mapping\path_mapping_portal.dat          # DryRun
.\Replace-AsisPath-v3.ps1 -Root "D:\src\portal" -Map .\mapping\path_mapping_portal.dat -Apply   # 적용
.\Replace-AsisPath-v3.ps1 -RootList .\replace_targets.dat                                       # 일괄 DryRun
.\Replace-AsisPath-v3.ps1 -RootList .\replace_targets.dat -Apply                                # 일괄 적용
```

**반드시 DryRun → 리포트 검토 → Apply → 재DryRun 0건** 순서. Apply는 변경 파일만
소스 옆 `<소스명>_backup_path_<시각>\`에 원본 상대경로 그대로 자동 백업한다.

---

## 3. 리포트 저장 규칙 (v8.2/v3 공통)

| 상황 | 저장 위치 |
|---|---|
| `-Out` 생략 (기본) | `report\<소스명>_asis_path_report.dat` (Find) / `report\<소스명>_asis_path_replace_report.dat` (Replace) — report 폴더 자동 생성 |
| `-Out` 직접 지정 (단일 모드) | 지정한 경로·이름 그대로 (폴더 없으면 자동 생성) |
| `-Out` 직접 지정 (일괄 모드) | 지정 폴더에 `<소스명>_<지정파일명>` — 소스별 분리를 위해 항상 접두 |

- 단일 모드도 소스명이 붙으므로 소스 30개를 순차 실행해도 리포트가 덮어써지지 않는다
- 소스 폴더명이 중복되면 자동 순번(`web`, `web_2`) + 경고
- 확장자는 .dat 유지 (회사 DRM의 csv 자동 암호화 회피). 엑셀은 텍스트 나누기(쉼표, 텍스트 한정자 ")로 조회 전용 — 엑셀에서 저장 금지

## 4. 목록 파일 형식

**Find용 roots.dat** — 한 줄에 폴더 경로 하나:
```
# 30개 소스 목록
D:\AppDev\workspace-egov\portal
D:\AppDev\workspace-egov\admin
```

**Replace용 replace_targets.dat** — `소스경로,매핑파일[,비고]` **2컬럼 필수** (소스마다 매핑이 다름):
```
D:\AppDev\workspace-egov\portal,D:\작업\mapping\path_mapping_portal.dat
D:\AppDev\workspace-egov\admin,D:\작업\mapping\path_mapping_admin.dat,비고 가능
```

Replace 일괄 모드는 **시작 전 전 소스·전 매핑을 사전 검증**하고, 하나라도 깨져 있으면
아무 소스도 건드리지 않고 중단한다 (중간 실패로 일부만 치환되는 사고 방지).

**매핑표 path_mapping_<소스명>.dat** — `OldPath,NewPath[,비고]`:
```
d:/eos/upload,d:/app/eos/upload,업로드 루트 이동
d:/eos,d:/app/eos,나머지 전체
```
- 구분자 / \ 무방 (소스 안의 d:/a, d:\a, d:\\a 전부 자동 매칭·스타일 보존 치환)
- 긴 경로 자동 우선, OldPath 중복 금지, 드라이브 루트 통짜 매핑(d:/,e:/) 금지 — 전부 스크립트가 검증
- **UTF-8 BOM으로 저장** (PS 5.1이 BOM 없는 UTF-8을 ANSI로 읽어 한글 비고 깨짐)

## 5. 주요 파라미터

### Find v8.2
| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `-Root` / `-RootList` | `C:\pgms` / (없음) | RootList 지정 시 Root 무시. WEB-INF 등 하위 폴더 직접 지정 가능 |
| `-Scope` | `all` | `all`(텍스트+CLASS+아카이브) / `src`(텍스트만) / `build`(CLASS+아카이브만) |
| `-Out` | `report\asis_path_report.dat` | 3장 규칙대로 소스명 접두 |
| `-Pattern` | `(?<![a-zA-Z0-9])[dD]:[/\\]` | 치환 후 특정 구경로 검증 시 교체 |
| `-ExcludeDirs` | `.git .svn .metadata node_modules bak backup` | src 모드면 `target bin build classes dist` 자동 추가. 직접 지정 시 기본값 **대체**됨 |
| `-ExcludeFiles` | `*.bak, *.back` | 파일명 패턴 제외 |

**[함정] WEB-INF 단독 조사 시 `-Scope src` 금지** — classes 폴더 제외 때문에 WEB-INF\classes를 놓친다. 기본값(all)으로.

### Replace v3
| 파라미터 | 기본값 | 설명 |
|---|---|---|
| `-Root` + `-Map` | `C:\pgms` / `path_mapping.dat` | 단일 모드 |
| `-RootList` | (없음) | 일괄 모드 (`소스경로,매핑파일`). 지정 시 Root/Map 무시 |
| `-Out` | `report\asis_path_replace_report.dat` | 3장 규칙대로 소스명 접두 |
| `-Apply` | (없음=DryRun) | 실제 치환 + 자동 백업 |
| `-ExcludeDirs` | `.git .svn .metadata node_modules target bin build classes dist` | 빌드산출물은 치환 대상 아님(재빌드 해소)을 기본값이 강제 |
| `-ExcludeList` | (없음) | 제외 파일 경로 목록 (엑셀 검토 후 특정 파일 제외용) |

- 백업 폴더(`*_backup_path_*`, `*_backup_ip_*`)는 두 스크립트 모두 항상 자동 제외 (v8.2/v2에서 정규식 수정 완료)
- exploded WEB-INF를 직접 치환해야 하면(운영 배포본) `-ExcludeDirs`에서 classes를 뺀 목록을 직접 지정

## 6. Replace 리포트 읽는 법

컬럼: `Status / File / RelPath / Ext / Line / Old / New / MapKey / Context`

| Status | 의미 | 조치 |
|---|---|---|
| REPLACE | 매핑에 걸림 — Apply 시 Old→New로 치환됨 | New 값·스타일 확인 후 Apply |
| UNMAPPED | d:/ 경로인데 매핑에 없음 | Context 보고 매핑 추가 or 의도적 보류 판정. 치환 완료된 새 경로는 UNMAPPED로 안 잡힘 |

Apply 요약에서 "치환 대상 N건인데 변경 파일 0개"면 스크립트가 Warning을 띄운다 — 비정상 상황이니 환경 확인.

## 7. 환경별 실행

**집 (테스트)**
```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\Find-AsisPath-v8.2.ps1 -Root "D:\src\portal"
```

**회사 (폐쇄망, bat 차단)**
1. 스크립트를 텍스트로 반입 → PowerShell ISE에 붙여넣기 (**UTF-8 BOM 유지**)
2. `Set-ExecutionPolicy -Scope Process Bypass`
3. F5 실행 — 파라미터는 못 넘기므로 상단 `param()` 기본값을 직접 수정:
   ```powershell
   [string]$Root     = "D:\src\portal",
   [string]$Map      = "D:\작업\mapping\path_mapping_portal.dat",   # Replace
   [string]$RootList = "D:\작업\replace_targets.dat",               # 일괄 모드
   [switch]$Apply    = $true                                        # 적용 시 (DryRun은 $false 유지)
   ```
   주의: v3는 `-Out` 기본값이 `report\...`로 바뀌었으므로 반입 후 param 블록 확인.

**검증 이력**: PS 7.4(컨테이너) + **PS 5.1 build 26100 실기기** 풀사이클 완료 (2026-07-27).
PS 5.1에서 v1(delegate 방식)은 치환이 조용히 실패하므로 반드시 v2 이상 사용.
