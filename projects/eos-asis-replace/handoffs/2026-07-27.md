# 핸드오프 — PS 5.1 풀사이클 검증 완료 + 버그 4건 수정 (2026-07-27)

집 PS 5.1(build 26100)에서 실소스 portal 풀사이클 완주. 과정에서 실버그 4건 발견·수정 → Replace v1→**v3**, Find v8→**v8.2**.

## 검증 완료 (PS 5.1 실기기 + PS 7.4 컨테이너)

- **풀사이클**: Find v8(all) 45건 → 매핑표 → Replace DryRun 6건 → Apply(변경 3파일, 백업 생성) → **재DryRun 치환 0건** ✅
- v3 일괄 모드(RootList)로도 Apply→재DryRun 0건 재확인 (스크린샷 증적)
- 백업본 = 치환 전 원본, 스타일 보존(`D:\\ISOs`→`D:\\app\\isos`), target 미접촉 — 컨테이너에서 실측

## 신규 기능

- **Replace v3 -RootList 일괄 모드** — 목록 형식 `소스경로,매핑파일[,비고]` (소스별 매핑이 다르므로 2컬럼 필수). **사전 전체 검증**: Apply 시작 전 전 소스·전 매핑 검사, 하나라도 깨지면 아무것도 안 건드리고 중단 (30개 중간 실패로 절반만 치환되는 사고 방지, 실측 확인). 소스별 백업 + 종합 요약표
- **기본 출력 통일**: 두 스크립트 모두 `-Out` 생략 시 영어 `report\` 폴더 자동 생성 후 `report\<소스명>_<기본파일명>` (증적 한글 폴더명 → 영어 전환)
- v2에 함께 들어간 것: Apply 정합성 경고(치환>0인데 변경 0 즉시 Warning — 버그 1 유형 자동 탐지), Copy-Item -LiteralPath, 드라이브 루트 통짜 매핑 가드

## 배운 것 (concepts/ 증류 후보)

- **PS 5.1에서 scriptblock→MatchEvaluator delegate는 단순 케이스는 되지만** (콘솔 스모크 테스트 통과했었음) 스크립트 파일 안에서 세션 함수를 참조하는 경우 조용히 무동작할 수 있음 → 5.1 타깃이면 delegate 대신 오프셋 재조립이 정답. "스모크 테스트 통과 ≠ 실전 통과"
- 치환 후 Find를 다시 돌리면 새 경로(d:/app/...)도 d:/ 패턴이라 검출됨 — **치환 완료 증적은 Replace 재DryRun 0건으로**, Find는 전수조사·특정 구경로(-Pattern 좁혀서) 검증용
- 자동 백업/자동 제외처럼 "알아서 해준다"는 기능은 반드시 실측으로 확인할 것 — 버그 3은 v8 개발 때 기능 명세만 있고 실측이 빠졌던 부분
