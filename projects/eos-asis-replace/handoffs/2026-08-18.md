# 핸드오프 — MAR/EOS AS-IS 치환 도구 (2026-08-18)

A 계열(경로/IP 치환) 도구에 **NAS·네트워크 경로**와 **IP/포트/도메인** 탐지를 넣었다.
그 과정에서 실측 리포트 2회를 받아 **오탐 8종을 잡았고, 놓치던 표기 3종을 회수**했다.
컨테이너 PS 7.4 기준으로 전 기능 실행 검증했으나 **PS 5.1 실기기 검증은 아직**이다.

## 오늘 확정한 것

### 1. 오탐 — 실측 리포트가 아니었으면 못 잡았다

1차 리포트(1390건): **1084건(78%)이 가짜**. 2차(1918건, domain 1829건): 대부분 가짜.

| 오탐 | 건수 | 정체 | 조치 |
|---|---|---|---|
| `//W3C//DTD`, `//mybatis.org//DTD` | 881 | DOCTYPE 공개식별자 `"-//W3C//DTD ..."` | `//host/share` 기본 OFF (`-UncSlash`로만) |
| `\d{1,3}` `\s+` `\w-` `\x20\t\r\n\f` | 203 | java/js **정규식 이스케이프** | UNC는 점 있는 호스트 or 2글자+호스트\2글자+공유명 |
| `java.io`, `java.net` | 644 | `import java.io.*;` — `.io`가 TLD 목록에 있었다 | 접미사에서 io/gov/info/biz/edu/mil/local 제거 + lookahead에 `*` `_` |
| `egovframework.gov` | 282 | taglib URI `http://egovframework.gov/ctl/ui` | 위 + ExcludeDomains |
| jQuery 계열 도메인 | 570+ | 벤더 JS 주석의 참고 링크 | ExcludeDomains 60여 개 |
| javadoc | 326 | `portal-1.0.0-javadoc.jar`, `package-tree.html` | `*-javadoc.jar`/`*-sources.jar` + javadoc HTML 기본 제외 |
| `C:\Users\...\.m2\...` | 209 | `maven-javadoc-plugin-stale-data.txt` | `*stale-data.txt` 기본 제외 |
| `2.3.4.726` | 2 | **ibatis 버전번호가 IP로** | IP 옥텟 0-255 검증 |
| `//uss/olp/...` (class) | 20 | 상수풀 **길이바이트가 0x2F(`/`)** | `//` OFF로 같이 소멸 |

> **원칙:** 제외는 조용히 하지 않는다. jar/도메인/IP 전부 `<리포트명>_skipped.dat`에 건수와 함께 남는다.
> 자체 jar나 진짜 우리 도메인이 잘못 걸러졌는지 여기서 확인한다.

### 2. 놓치던 표기 — `FindTest.java` 픽스처로 회수

내가 오탐을 막으려고 건 조건이 진짜 대상을 같이 막고 있었다.

| 표기 | v9.3까지 | 원인 | v9.6/9.7 |
|---|---|---|---|
| `"Z:"` `"T:"` | 누락 | `[A-Za-z]:` 뒤 구분자 필수(`forward:/` 오탐 방지용) | 따옴표 완전 포함 / `=` 뒤 줄끝이면 인정 |
| `"\\nas"` `"\\windbvs1"` | 누락 | `\\d` 이스케이프와 구분 불가라 포기했었음 | 같은 조건 + 호스트 2글자↑ + `x##`/`u####` 제외 |
| `jdbc:oracle:thin:@dbsvr.co.kr:1521` | 누락 | 도메인 앞 경계에서 `@` 차단(메일 오탐 방지) | `@` 허용 (대신 메일 도메인도 잡힌다) |

검증: `"\\d{1,3}"` `"\\s"` `"\\."` `"[\\x20\\t\\r\\n\\f]"` `"\\\\"` `"\\u00A0"` `split("\\|")` 전부 0건 유지.

### 3. 매핑드라이브 실측 — 같은 `Z:`가 시스템마다 다른 곳을 가리킨다

```
모바일디빈스 W: = \\10.10.18.229\image
모바일DM     Z: = \\nas_digitsign_rdon\digitsign_rdon
             X: = \\nas_mobiledb\MobileDB
             T: = \\10.10.18.229\midmfs9
모바일CSI    Y: = \\10.10.17.239\wormsdata15
             Z: = \\windbvs1\MCSI_Res$        ← DM의 Z:와 다른 서버
```

**매핑표를 전 소스 공용으로 쓰면 엉뚱한 서버로 치환된다.** 소스별 매핑파일 분리가 필수
(`replace_targets.dat`의 `소스경로,매핑파일`). 이 사실 때문에 `Get-MappedDrives.ps1`을 새로 만들었다.

### 4. 실제 치환 대상 (2차 리포트에서 오탐 걷어낸 결과)

```
path : D:\app\ant / D:\app\ant\old / D:/ / Y:\ / d:/app/file
ip   : 10.10.88.165(2) / 10.88.33.145 / 10.10.88.134   ← .class 상수풀에도 존재
port : 20300(Altibase) / 1521 / 3306 / 33000 / 8629
domain: nia.or.kr 1건 (판단 필요)
```

`#Globals.Url=jdbc:Altibase://127.0.0.1:20300/mydb`, `Test.class`의 `Mypath`/`MyIp` 필드가 근거.

## 미해결 이슈 (다음 세션 최우선)

1. **PS 5.1 구문 검증** — 전부 컨테이너 PS 7.4에서만 돌렸다. 5.1은 파서가 다르다.
   집에서 `powershell -ExecutionPolicy Bypass -File .\Find-AsisPath.ps1 -Root . -Inventory` 로
   **배너에 `v9.7`이 찍히는지**부터 확인. 안 찍히면 구버전이거나 파싱 실패다.
   (문자열 보간 안 중첩 따옴표는 이미 제거했지만 5.1 실행 이력은 없다)
2. **`Get-MappedDrives.ps1` 실기기 확인** — `Win32_MappedLogicalDisk` 경로가 회사 PC에서 되는지.
   **WAS가 서비스 계정으로 돌면 대화형 세션과 매핑이 다르다** — 그 계정으로 `net use`를 떠야 정확하다.
   못 올리는 서버는 `net use > netuse.txt` → `-FromNetUse`.
3. **`_skipped.dat` 역검토** — 제외 목록에 **진짜 우리 도메인/자체 jar**가 섞였는지.
   `egovframework-*`와 `commons*`가 위험하다(사내 공통 모듈이 같은 이름을 쓸 수 있다).
4. **소스별 매핑표 작성** — `Get-MappedDrives -EmitMapping` 산출물을 시스템별로 받아
   `replace_targets.dat`에 `소스경로,매핑파일`로 묶는다.

### 검증 증적 (컨테이너 PS 7.4)

- 풀사이클: DryRun 9건 → Apply(백업 md5 = 원본) → **재DryRun 0건**
- 스타일 보존: `d:/a` / `D:\a` / `D:\\a`(java 리터럴) / `\\nas\share` / `\\\\nas\\share` / `//nas/share` 각각 유지
- 드라이브루트→UNC: `"Z:"` → `"\\\\nas_x\\share"`(java 이스케이프까지), `Z:\data` 접두, `c=Y:/list` → `//host/share/list`
- EUC-KR 한글 파일 바이트 보존, 숨김공유 `MCSI_Res$` 처리
- 오탐 0 유지: `http://nasweb/share`, `forward:/eos`, `d:/eosdata`, yaml `key: value`, JSON `"a":"b"`, 삼항 `x:y`

## 이어서 할 때 참고

- **실측 리포트가 유일한 검증 수단이다.** 합성 픽스처로는 DOCTYPE 공개식별자도, 상수풀 길이바이트
  0x2F도, maven stale-data도 상상하지 못했다. 새 Kind를 추가하면 **반드시 실소스 1회 돌려 상위 Target을 눈으로 볼 것.**
- **오탐 방지 조건이 진짜 대상을 막는다.** `forward:/` 막으려던 규칙이 `"Z:"`를, `\\d` 막으려던 규칙이
  `"\\nas"`를, 메일 막으려던 규칙이 jdbc `@host`를 막고 있었다. 조건을 걸면 **막히는 쪽 예시도 같이 적어둘 것.**
- **제외에는 증적을 남긴다** (`_skipped.dat`). 조용한 제외는 나중에 "왜 안 나오지"로 돌아온다.
- **아직 못 잡는 것**: 런타임 조립형 (`Drive3 + "\\data"`는 `Drive3`만 / `System.getProperty("user.dir")` /
  `File.separator` 조합), 백슬래시 3개 이상 이중 이스케이프(조사는 됨, 치환은 UNMAPPED로 표시),
  공유명 1글자 UNC(따옴표로 안 감싸인 경우).
- `-File` 실행은 배열 파라미터를 문자열로 뭉갠다 → 세 스크립트 모두 콤마를 직접 쪼갠다.
  단 `@()`는 안 먹으므로 제외 해제는 `-ExcludeJars ""` 형태로 쓴다.
