# 핸드오프 — AS-IS 경로/IP 치환 작업 (2026-07-25)

## 프로젝트 맥락

- 레거시 EOS 소스 복구/이관 프로젝트 (eGovFrame 기반, Ant/Ivy, LENA WEB/WAS, 폐쇄망)
- 현재 작업: AS-IS 하드코딩 **경로(d:/ 형태)** 및 **AS-IS IP → TO-BE IP** 치환
- 대상 소스 약 **30개**, 소스별로 1회씩 개별 실행 방침
- 집(Maven, eGovFrame 5.0.1 테스트 환경)과 회사(레거시 Ant, 폐쇄망) 양쪽에서 사용

## 오늘 이해한 것 (개념)

- 치환 범위 원칙: 텍스트 파일만 직접 치환. class=재빌드, jar/war=재패키징으로 해소. CLASS에서만 검출 + 대응 java 없음 = 소스 유실분(CFR 디컴파일 대상) 신호
- 검색 패턴: 경로 `(?<![a-zA-Z0-9])[dD]:[/\\]` (lookbehind로 forward:/ 오탐 방지), IP 전수 `(?<![\d.])(?:\d{1,3}\.){3}\d{1,3}(?![\d.])`, 특정 IP는 `\.` 이스케이프 필수
- 회사 DRM: csv/txt 자동 암호화, **`.dat` 확장자는 암호화 미대상** → 매핑표·리포트 모두 `.dat`로 운용. 편집은 메모장만(엑셀 저장 금지), 엑셀은 텍스트 나누기로 조회 전용
- 회사 반입 제약: bat 실행 차단 → ps1은 텍스트 전달 후 PowerShell ISE 붙여넣기 → F5. 실행 정책은 `Set-ExecutionPolicy -Scope Process Bypass`
- 스크립트는 UTF-8 BOM 필수 (없으면 PS 5.1에서 한글 주석 깨져 파서 에러)

> 안정화되면 `concepts/drm-dat-운용.md`, `concepts/검색패턴-정규식.md` 등으로 증류 예정

> 스크립트·가이드 실물은 `artifacts/`에 보관 (또는 코드 레포 커밋 해시로 링크)

## 소스 1건당 표준 흐름 (확정)

```
1. Find -Scope src → 경로/IP 목록 (치환 전 증적)
2. 경로 치환 (이클립스 Replace 또는 수동)
3. Replace-AsisIp DryRun → 엑셀 검토 → 제외 반영 → -Apply → DryRun 0건
4. 재빌드
5. Find -Scope build (OldIP/구경로 패턴) → 0건 확인 (치환 후 증적)
6. 파일 외 확인: DB 설정 테이블 / LENA·workers.properties / hosts / 방화벽
```

## 검증 이력 (테스트 완료 항목)

- 경로 검색: java 리터럴, properties, target/classes 복사본, class 바이너리, war 내부(WEB-INF/classes의 class·properties) 모두 검출 확인
- forward:/ 오탐 제거 확인, 중첩 jar 압축바이트 가짜매칭 버그 수정 확인
- IP 치환 DryRun: 127.0.0.1 테스트로 2파일 7건 검출·업무명 매핑 표시 확인 (**Apply는 아직 미테스트**)
- BOM 인코딩 이슈(PS 5.1 파서 에러) 해결 확인

## 미해결 이슈 (다음 세션 최우선)
