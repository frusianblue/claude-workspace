**PS 5.1 실기기 검증을 처음으로 통과**했고, 그 과정에서 컨테이너 검증이 못 잡는 버전차 2건을 잡았다.

## 오늘 확정한 것

### 1. PS 5.1 구문 검증 — 통과 (부분)

`Find-AsisPath.ps1 -Root . -Inventory` 실행, 배너 `v9.7` 출력 확인.
1차 핸드오프 미해결 1번의 **절반**이 해결됐다.

**나머지 절반이 남은 이유:** `-Inventory`는 `if ($Inventory) { ... return }`으로 조기 반환한다.
파일 전체가 파싱된 건 맞지만, **v9.7에서 새로 넣은 정규식 조립부·`Kind`/`Target`/`Value` 컬럼 생성부는
5.1에서 한 줄도 실행되지 않았다.** 배너가 떴다고 런타임 검증이 끝난 게 아니다.

### 2. `Get-MappedDrives` v1 → v1.1 — 실행 검증 완료

집 PC엔 네트워크 드라이브가 없어 `-EmitMapping`까지 못 가고 `exit 1` 했다.
`-FromNetUse` 픽스처(`netuse.dat`)로 우회해 전 코드 경로를 덮었다.

| 검증 항목 | 결과 |
|---|---|
| 배너 `v1.1` | 패치 반영 확인 |
| 4개 수집 (T/X/Y/Z) | OK |
| **`$pending` 분기** | **첫 실행.** 줄바꿈으로 갈라진 `net use` 출력에서 `Y:` 회수 성공 |
| `Hidden` / `IsIp` 판정 | `MCSI_Res$` → 숨김공유, `10.10.18.229` → IP직접 |
| `-Hosts` 에서 IP 제외 | 3개만 출력 (10.10.18.229 빠짐) |
| `report\*.dat` 한글 | `"모바일DM"` 정상 — BOM 패치 검증 |

`$pending` 분기(드라이브만 있는 줄 → 다음 줄에서 UNC 회수)는 **지금까지 한 번도 실행된 적이 없던 코드**다.
실서버 `net use`는 UNC가 길면 실제로 이렇게 감기므로, 이게 확인된 게 이번 세션에서 제일 크다.

### 3. 컨테이너(PS 7.4) 검증이 못 잡는 버전차 2건

1차 핸드오프의 "PS 7.4에서 전 기능 실행 검증" 이 **회사에서 같은 결과를 보장하지 않는 지점**이다.

| API | PS 5.1 | PS 7.x | 결과 |
|---|---|---|---|
| `Export-Csv -Encoding UTF8` | BOM **有** | BOM **無** | 7.x로 만든 `.dat`를 5.1로 읽으면 한글이 ANSI(MS949)로 읽혀 깨짐 |
| `[IO.File]::WriteAllLines` | CRLF | **LF** (리눅스) | 컨테이너 산출물만 개행이 다름 |

둘 다 `[IO.File]::WriteAllText` + `UTF8Encoding($true)` + `-join "\`r\`n"` 으로 고정해 버전 무관하게 만들었다.
**`-Encoding UTF8` 문자열은 버전마다 의미가 다르다 — BOM이 필요하면 인코더 객체를 직접 넘길 것.**

### 4. `ExcludeDomains` 판정은 '완전일치 or 라벨경계 접미사'

```powershell
$hit = if ($p.Contains("*")) { $v -like $p } else { ($v -eq $p) -or $v.EndsWith("." + $p) }
```

→ **`www.redhat.com`이 아니라 `redhat.com`을 등록해야 한다.** `www.` 붙은 표기를 넣으면
`redhat.com` 단독 표기가 그물을 빠져나간다. 1차 리포트에 `dthmlgoodies.com`(오타)과
`www.dhtmlgoodies.com`이 둘 다 올라온 게 이 문제가 실재한다는 증거다.

### 5. `javax.net`은 도메인이 아니라 자바 패키지

`import javax.net.ssl.SSLSocketFactory;` 가 도메인으로 잡힌 것. 8/12에 `java.io`/`java.net` 644건을
`DomainSuffix`에서 `io` 제거 + lookahead `*`/`_` 추가로 잡았는데, `javax.net.ssl.XXX`는 뒤에 `.*`가
없어 그 그물을 빠져나간다. **이름으로 막았으므로 `sun.net`, `com.sun.net`이 또 나온다.**
다음에 나오면 이름 추가가 아니라 **`import` 줄 자체를 거르는 구조**로 바꿀 것.

## 이어서 할 때 참고

- **배너가 떴다 = 파싱 통과. 런타임 통과가 아니다.** `-Inventory`처럼 조기 `return`하는 모드로는
  본체가 안 돌아간다. 검증 모드를 고를 때 **그 모드가 어디까지 실행되는지**를 먼저 볼 것
- **컨테이너 검증은 버전차를 못 잡는다.** `Export-Csv -Encoding UTF8`(BOM)과 `WriteAllLines`(개행)가
  실증 사례. **`-Encoding UTF8` 문자열은 버전마다 의미가 다르다** — BOM이 필요하면 인코더 객체를 직접 넘길 것.
  `-shl` byte 잘림 / PS위치≠.NET위치 와 같은 급의 함정. RUNBOOK "알려진 함정" 표에 추가할 것
- **제외 목록에 넣는 순간 그건 리포트에서 사라진다.** 실치환 후보(`nia.or.kr`)는 위치를 확인하기
  전엔 넣지 않는다. 벤더 주석 링크와 성격이 다르다
- **오탐 이름을 하나씩 막는 건 임시방편이다.** `javax.net`이 그렇다 — 같은 계열이 또 나오면
  이름 추가를 반복하지 말고 구조(`import` 줄 제외)로 갈 것
- 같은 날 두 번째 핸드오프는 **`YYYY-MM-DDb.md`** — `-2`는 대시보드가 구버전을 집는다 (상단 주석)
